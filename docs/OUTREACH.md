## Google Form

Live form: https://forms.gle/mnZFhTYNUSR8GkZr7

Questions (in order):

1. Your name *(short answer)*
2. Your wallet address *(short answer, required)*
3. Your transaction hash *(short answer, required)* - lets a judge verify
   the wallet actually called our Preprod contract
4. How did you use Anonymous Whispers *(multiple choice, required)*:
   Reporter / Organization / Both
5. Did the app work as expected? *(multiple choice, required)*:
   Yes / Mostly / No
6. What could be improved? *(long text)*
7. Would you use this again? *(multiple choice, required)*:
   Yes / Maybe / No

Email is auto-collected by Google Forms for follow-up and is not published
on the public user list.

Set the form's response destination to a Google Sheet so all rows can be
bulk-pasted into `USERS.md` and `docs/FEEDBACK.md`.
