# User Feedback - Level 5

The feedback loop for Anonymous Whispers on Preprod. Raw responses from real
users, the themes that emerged, and the changes those themes drove in the
product.

## Feedback Collection Method

Feedback is collected through a Google Form linked from every outreach
message (Discord, Telegram, X, WhatsApp, in-person sessions). The form
takes under 90 seconds:

1. Your name
2. Your wallet address (required)
3. Your transaction hash (required, so a judge can verify on-chain)
4. How did you use Anonymous Whispers: Reporter / Organization / Both (required)
5. Did the app work as expected: Yes / Mostly / No (required)
6. What could be improved? (long text)
7. Would you use this again: Yes / Maybe / No (required)

Email is auto-collected for follow-up and is not published on the public
user list.

Form link: https://forms.gle/mnZFhTYNUSR8GkZr7

Direct DMs and in-person session notes are also folded into the raw log
below, labelled by channel.

## What We Heard (Themes)

Grouped from the "what could be improved" field, counted by how many users
raised each. The large majority (about 40 of 51) reported no problems at all
("all good", "worked smoothly", "nice and clean"), so the actionable signal
came from a small number of repeated issues:

| Theme | Users | What they said |
|-------|-------|----------------|
| Wallet auto-picked the wrong extension | 3 | With both 1am and Lace installed, the connect flow grabbed the wrong wallet first |
| Report form reset after submit | 3 | The form cleared or unmounted during the post-submit ledger refresh, forcing a redo |
| Landing page slow on first load | 2 | First paint felt heavy the first time the page opened |
| No quick way to copy the tx hash | 1 | Wanted a one-click copy for the transaction hash after submitting |

Everything else was positive sentiment with no specific ask.

## What We Changed

We prioritised the three repeated themes (raised by 2 or more users), plus the
tx-hash copy request since it overlapped with our own onboarding need (users
have to send us their tx hash to be verified). None of these touched
`contract/src/anonymous-whispers.compact`, so no redeploy was needed.

| Change | Reason (Theme) | Commit |
|--------|----------------|--------|
| Prefer the 1am wallet over Lace in the connect auto-pick, and translate wallet channel-shutdown errors into a clear reconnect prompt | Wallet auto-picked the wrong extension (3 users) | `1d04ab5`, `45d0616` |
| Keep the report form mounted through the post-submit ledger refresh so it no longer resets | Report form reset after submit (3 users) | `2b2e064` |
| Code-split routes so landing no longer ships the Midnight WASM, and preload the app-route chunks on idle so navigation stays instant | Landing page slow on first load (2 users) | `eb7db0b` (code-split), plus the idle route-preload commit |
| Add a copyable tx hash panel after submit and register, showing the real transaction hash instead of the internal ZK identifier | Wanted a quick way to copy the tx hash (1 user) | `01e1947`, `6901b94` |
